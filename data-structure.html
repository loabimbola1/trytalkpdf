1. Entity Inventory (The 13 "Things")

TalkPDF tracks 13 distinct concepts to power diagnosis, micro-interventions, active recall evaluation, and parent reporting:

1
Student
SS3 candidate taking diagnostic tests and closing gaps.
2
Parent
Paying sponsor receiving WhatsApp summaries & reports.
3
Curriculum Objective
WAEC/JAMB syllabus topic, rule & required concepts.
4
Diagnostic Question
5 past-exam questions linked to syllabus objectives.
5
Question Option
Multiple-choice options pre-tagged with misconceptions.
6
Micro-Intervention
60–90 second plain-English conceptual lesson.
7
Learning Session
Tracks active study lifecycle from quiz to completion.
8
Diagnostic Response
Student's answers and mapped likely gaps.
9
Explain-Back Record
Student's explanation, AI evaluation & rubric scores.
10
Parallel Question
Fresh question testing identical concept to verify closure.
11
Learning-Gap Status
PROVISIONALLY_RESOLVED or PERSISTENT_GAP state.
12
Parent Progress Report
WhatsApp payload & secure, read-only revocable link.
13
Tutor Escalation Ticket
Human tutoring request for unresolved persistent gaps.

2. Detailed Facts & Fields to Store per Entity

1. Student (Candidate Profile)
Entity: Student
Represents the SS3 secondary school candidate preparing for WAEC or JAMB.
FieldTypeDescription
student_idUUID / StringPrimary unique identifier.
full_nameStringCandidate's full name (e.g., Samuel Okon).
target_examEnumWAEC, JAMB, or BOTH.
class_levelStringAcademic level (default: SS3).
phone_numberStringMobile phone number or shared family device number.
parent_idUUID / StringForeign key to the linked Parent entity.
current_streak_countIntegerConsecutive gaps provisionally resolved (FR-14).
low_bandwidth_enabledBooleanPreference flag for text-first low data mode (FR-08).
created_atTimestampAccount creation timestamp.
last_active_atTimestampTimestamp of latest study session.
2. Parent (Economic Buyer / Guardian)
Entity: Parent
The family sponsor financing exam fees and receiving objective accountability updates.
FieldTypeDescription
parent_idUUID / StringPrimary unique identifier.
full_nameStringParent or guardian's full name.
whatsapp_numberStringE.164 formatted number for WhatsApp dispatch (FR-09).
sms_numberStringFallback SMS mobile number.
relationshipStringRelationship (Mother, Father, Guardian).
notification_opt_inBooleanConsent to receive WhatsApp progress reports.
linked_student_idsList<UUID>Array of student accounts under this parent.
created_atTimestampRegistration timestamp.
3. Curriculum Objective
Entity: CurriculumObjective
Granular syllabus objective from the official WAEC/JAMB curriculum scheme.
FieldTypeDescription
objective_idStringObjective code (e.g., PHY-EM-001).
exam_typeEnumWAEC or JAMB.
subjectStringSubject name (Physics, Chemistry, etc.).
topicStringBroad syllabus topic (e.g., Electromagnetism).
subtopic_titleStringSpecific concept (Faraday's Law of Induction).
objective_statementStringFormal syllabus learning goal statement.
required_understanding_pointsList<String>Human-defined key concepts AI checks during Explain-Back (FR-05).
created_atTimestampAuthoring timestamp.
4. Diagnostic Question
Entity: DiagnosticQuestion
Past-exam question linked to an objective, part of the 5-question diagnostic quiz.
FieldTypeDescription
question_idUUID / StringPrimary unique identifier.
objective_idStringForeign key to Curriculum Objective.
exam_sourceStringPast-exam reference (WASSCE 2022 Question 14).
question_textTextFull question problem text.
diagram_urlString (Optional)URL for schematics, circuits, or diagrams.
correct_optionChar(1)Correct option letter (A, B, C, or D).
created_atTimestampAuthoring timestamp.
5. Question Option & Misconception Tag
Entity: QuestionOption
Individual multiple-choice options pre-tagged at authoring time with likely misconceptions.
FieldTypeDescription
option_idUUID / StringPrimary unique identifier.
question_idUUID / StringForeign key to Diagnostic Question.
option_letterChar(1)Option letter (A, B, C, or D).
option_textTextOption text or formula string.
is_correctBooleanTrue if this is the correct answer.
likely_misconception_titleStringAssociated likely learning gap title (FR-01, FR-02).
likely_misconception_explanationTextExplanation of why this incorrect logic occurs.
6. Targeted Micro-Intervention
Entity: MicroIntervention
Bite-sized 60–90 second conceptual lesson resolving the diagnosed misconception.
FieldTypeDescription
intervention_idUUID / StringPrimary unique identifier.
objective_idStringForeign key to Curriculum Objective.
targeted_misconception_titleStringThe exact likely learning gap addressed (FR-03).
explanation_textText60–90 second plain-English explanation.
key_formula_or_ruleStringCore formula or rule summary.
audio_snippet_urlString (Optional)URL for audio voice snippet playback (FR-03).
created_atTimestampAuthoring timestamp.
7. Learning Session
Entity: LearningSession
Lifecycle record tracking a student's active diagnostic and resolution cycle.
FieldTypeDescription
session_idUUID / StringPrimary unique identifier.
student_idUUID / StringForeign key to Student.
objective_idStringForeign key to Curriculum Objective.
statusEnumDIAGNOSTIC_ACTIVE, EXPLAIN_BACK_PENDING, PARALLEL_ACTIVE, COMPLETED.
low_data_modeBooleanTrue if text-first lightweight mode was used (FR-08).
local_cache_keyStringLocal storage cache key for async session recovery (FR-10).
started_atTimestampSession start timestamp.
completed_atTimestampSession completion timestamp.
8. Diagnostic Response
Entity: DiagnosticResponse
The student's answer selection on a diagnostic question.
FieldTypeDescription
response_idUUID / StringPrimary unique identifier.
session_idUUID / StringForeign key to Learning Session.
question_idUUID / StringForeign key to Diagnostic Question.
selected_option_letterChar(1)Selected letter (A, B, C, D).
is_correctBooleanTrue if answer was correct.
isolated_gap_titleStringPre-tagged likely misconception if incorrect (FR-02).
time_spent_secondsIntegerTime elapsed answering the question.
answered_atTimestampSubmission timestamp.
9. Explain-Back Record
Entity: ExplainBackRecord
Student's own-words active recall submission, AI evaluation, and secondary feedback.
FieldTypeDescription
explain_back_idUUID / StringPrimary unique identifier.
session_idUUID / StringForeign key to Learning Session.
student_idUUID / StringForeign key to Student.
attempt_numberInteger1 for initial attempt, 2 for single retry (FR-04).
input_formatEnumTEXT or AUDIO_VOICE_NOTE (FR-12).
raw_submission_textTextStudent's own-words explanation or audio transcript.
audio_file_urlString (Optional)Audio recording URL if voice dictation was used.
primary_evaluation_resultEnumUNDERSTOOD or NEEDS_CLARIFICATION (FR-05).
matched_understanding_pointsList<String>Predefined points identified in explanation.
missing_understanding_pointsList<String>Predefined points missing.
targeted_hint_issuedText (Optional)Targeted hint delivered for retry on clarification (FR-05).
secondary_simplicity_scoreIntegerScore out of 10 (FR-05).
secondary_accuracy_scoreIntegerScore out of 10 (FR-05).
secondary_analogies_scoreIntegerScore out of 10 (FR-05).
secondary_overall_scoreIntegerComposite score out of 100 (FR-05).
secondary_badge_awardedEnumGOLD, SILVER, or BRONZE.
evaluated_atTimestampAI evaluation timestamp.
10. Parallel Reassessment Question
Entity: ParallelQuestion
A fresh past-exam question testing the identical syllabus objective to verify gap closure.
FieldTypeDescription
parallel_question_idUUID / StringPrimary unique identifier.
objective_idStringForeign key to Curriculum Objective.
diagnostic_question_refUUID / StringReference to initial diagnostic question failed.
exam_sourceStringPast-exam metadata (JAMB UTME 2021 Question 28).
question_textTextComplete parallel problem text.
diagram_urlString (Optional)Optional image schematic.
option_a, option_b, etc.TextOption choices text.
correct_optionChar(1)Correct option key (A, B, C, or D).
created_atTimestampAuthoring timestamp.
11. Learning-Gap Resolution Record
Entity: LearningGapResolution
The definitive empirical outcome: PROVISIONALLY_RESOLVED vs. PERSISTENT_GAP.
FieldTypeDescription
gap_resolution_idUUID / StringPrimary unique identifier.
session_idUUID / StringForeign key to Learning Session.
student_idUUID / StringForeign key to Student.
objective_idStringForeign key to Curriculum Objective.
diagnosed_gap_titleStringThe misconception addressed.
parallel_question_idUUID / StringForeign key to Parallel Question.
selected_optionChar(1)Option picked by student.
is_parallel_correctBooleanTrue if parallel question was answered correctly.
final_gap_statusEnumPROVISIONALLY_RESOLVED or PERSISTENT_GAP (FR-06, FR-11).
permanent_mastery_confirmedBooleanAlways false at initial test; pending future reassessment.
scheduled_reassessment_dateDate (Optional)Date queued for confirmation reassessment.
tutor_escalation_statusEnumNONE, PROMPTED, REQUESTED, RESOLVED (FR-13).
resolved_atTimestampResolution timestamp.
12. Parent Progress Report & Secure Token
Entity: ParentReport
Parent deliverables: WhatsApp summary payload and non-guessable, read-only private web link.
FieldTypeDescription
report_idUUID / StringPrimary unique identifier.
session_idUUID / StringForeign key to Learning Session.
student_idUUID / StringForeign key to Student.
parent_idUUID / StringForeign key to Parent.
topics_assessed_countIntegerNumber of syllabus topics tested.
gaps_identified_countIntegerNumber of likely learning gaps identified.
gaps_provisionally_resolved_countIntegerNumber of gaps marked PROVISIONALLY_RESOLVED.
persistent_gaps_countIntegerNumber of gaps marked PERSISTENT_GAP.
pre_readiness_scoreInteger (%)Initial readiness index (e.g. 62%).
post_readiness_scoreInteger (%)Updated readiness index (e.g. 74%).
whatsapp_summary_textTextMessage body dispatched via WhatsApp (FR-09).
whatsapp_dispatch_statusEnumPENDING, SENT, DELIVERED, FAILED.
secure_web_tokenStringCryptographic non-guessable token (FR-07).
secure_report_urlStringPrivate read-only URL without parent login.
is_token_revokedBooleanTrue if URL has been revoked (FR-07).
token_expires_atTimestampExpiration date/time (e.g., 30 days).
generated_atTimestampReport generation timestamp.
13. Tutor Escalation Ticket
Entity: TutorEscalationTicket
Escalation ticket generated when an unresolved persistent gap requests human tutoring.
FieldTypeDescription
ticket_idUUID / StringPrimary unique identifier.
gap_resolution_idUUID / StringForeign key to Learning-Gap Resolution.
student_idUUID / StringForeign key to Student.
parent_idUUID / StringForeign key to Parent.
objective_idStringForeign key to Curriculum Objective.
diagnosed_gap_summaryTextPre-attached diagnosis detailing misconception & failed question.
student_explain_back_snippetTextStudent's explanation attempt and missing points.
ticket_statusEnumNEW, ASSIGNED_TO_TUTOR, LESSON_SCHEDULED, RESOLVED.
created_atTimestampTicket creation timestamp.
